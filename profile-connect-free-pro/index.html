🔒 100% Safe & Non-Destructive: Connecting users will never delete any user accounts, passwords, or existing metadata. It only links accounts to your chosen User Registration form and safely copies mapped values.

Profile Field Mapping (Optional)

Copy existing user profile data from other sources into your User Registration form fields upon connection.

⚡ How field mapping works:

  • One-time copy: When you connect users, the values from your source keys are copied once into their User Registration profile. Existing data in your source keys is never deleted or modified.
  • Optional: If you only want users to have access to the form without copying legacy metadata, you can leave field mappings empty.
